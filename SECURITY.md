# Security and privacy

This plugin writes diagnostics locally and does not send data over the network.
Crash tracebacks may contain user names, local file paths and function names.
Review logs before attaching them to public issues; share only the relevant,
redacted session. Do not commit crash logs to this repository.

If a security report contains sensitive information, contact
**tnct.yoko.hiro@gmail.com** rather than opening a public issue with the data.
For ordinary bugs, open an issue with the plugin, Moleditpy and Python versions,
operating system, reproduction steps and a redacted traceback when available.
